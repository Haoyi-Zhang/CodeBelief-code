# Fixed ordinary-Horn formulas and replay

Let A be a finite set of positive propositional atoms. A clause is B -> h with B subset A and h in A union {false}. Empty B is allowed. Negative unit not-p is represented as {p}->false. Negative antecedents are not allowed. The clauses are interpreted classically.

## H1. Soundness and completeness of forward closure

Start with K empty. Whenever B subset K and h is a positive atom, add h to K. If B subset K for a clause with false head, report unsatisfiable. If an entire scan adds nothing and no false head fires, stop with K.

Termination follows because each changing scan adds an atom and there are finitely many atoms. Soundness follows by induction: every atom added to K is true in every model of the original formula, since all atoms in its clause body are already true in every model. If false is reached, no model can exist.

For completeness, suppose saturation ends without false. Define valuation v(a)=true exactly when a belongs to K. Every clause with a false antecedent is satisfied. If its body is true under v, then B subset K. Saturation ensures that a positive head belongs to K, and a false head would have fired. Thus every clause is satisfied by v. Hence unsatisfiability is reported exactly for unsatisfiable formulas. The same induction proves that K is contained in every satisfying valuation, so it is the least model when satisfiable.

The implementation rescans the clauses. No linear-time implementation or novel Horn satisfiability theorem is claimed. The executable finite checks are not a mechanization of this general argument.

## H2. Derivation certificates

A derivation lists named clauses. Replay starts with no known positive atoms, checks that every body's atoms are known before using its clause, and adds its head. A false head must be the last step. By H1's induction, acceptance proves unsatisfiability of the fixed listed clauses. Repeated use of a clause and redundant positive-head derivations are rejected by the implemented format. These format restrictions still permit a derivation generated by the closure procedure.

## H3. Inclusion-minimality certificates

Let C be the fixed set of clauses claimed as a core. A valid derivation proves C unsatisfiable. Supply, for each c in C, a Boolean valuation satisfying C minus {c}; replay checks each assignment directly.

If a proper subset D of C were unsatisfiable, choose c in C minus D. The supplied model of C minus {c} would also satisfy D, a contradiction. Therefore C is inclusion-minimal. Conversely, an inclusion-minimal unsatisfiable finite C has such a satisfying assignment after each deletion, and H1 supplies its derivation. This certifies inclusion minimality for the fixed Horn formula, not minimum cardinality among cores and not minimum source support under re-mining.

## H4. Why unrestricted signed antecedents are outside scope

Consider classical implications (not-p)->p and p->(not-p). Their conjunction is unsatisfiable: p=false violates the first implication and p=true violates the second. A naive algorithm treating positive and negative atoms as independent forward-chaining symbols, starting without either symbol, derives neither and misses the contradiction. Completeness of H1 therefore does not extend merely by allowing signed antecedents. No such extension is implemented or claimed.
