# Time and uncertainty boundaries

## T1. Time-indexed disagreement is not a contradiction

Let x_0 and x_1 be distinct propositional atoms. The formula x_0 and not-x_1 is satisfiable by x_0=true, x_1=false. Adding the persistence premise x_0=x_1 makes it unsatisfiable. These statements are checked by all four Boolean valuations in the artifact, and the displayed assignment is a complete mathematical argument.

The code index binds a certificate to one original ordered snapshot. It does not prove that two matching function names describe one unchanging semantic obligation. A general history witness would need an explicit admissibility rule for bridges and a cost/selection model for retained changes. Neither exists in this checkpoint. The four source snapshots are manually constructed controls, not a mined software history.

## U1. Observation-only defect calibration is unidentified

Let O be a fixed support observation and let a scoring rule return r(O) in [0,1]. Consider two possible distributions that give O probability one. In the first distribution the true defect label Y is always zero; in the second it is always one. The scoring rule sees identical observations and returns the same r in both. Calibration for the first distribution requires r=0; calibration for the second requires r=1. These requirements cannot both hold.

This elementary argument concerns absence of assumptions connecting observations to labels. It does not rule out calibration under a specified sampling/labeling model, and is not offered as a new learning-theory theorem. No labeled practical data, probability model, or statistical calibration experiment was available in this checkpoint. Consequently support ratios are treated solely as exact deterministic activation thresholds, not probabilities of programmer intent or actual defects.
